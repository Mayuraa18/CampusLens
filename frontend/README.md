# CampusLens Frontend

Frontend for the CampusLens AI document understanding application.

## Goal

The frontend should allow students to:

- Upload confusing academic documents
- View document summaries
- View important deadlines
- View required actions
- Ask questions about documents
- View source references
- Interact with the CampusLens AI agent

## Current Status

Frontend framework: To be decided by the frontend team.

## Backend API

The backend will be provided by the Django team.

Expected API areas:

- Document upload
- Document listing
- Document details
- Document summary
- Deadlines
- Actions
- Document chat

## Important

Keep API calls separated from UI components so the frontend can easily connect to the Django backend later.
